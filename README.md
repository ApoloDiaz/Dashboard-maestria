# Trayectorias de deterioro cognitivo en Alzheimer: EDA

Dashboard interactivo (sitio estático) con el análisis exploratorio de una cohorte longitudinal de 118 pacientes, 13 pruebas neuropsicológicas y evaluaciones a los 0, 12 y 18 meses.

## Archivos
- `index.html`: página y lógica del dashboard.
- `d3.min.js`: biblioteca D3 v7 (gráficos).
- `data.js`: datos anonimizados usados por el dashboard.

## Despliegue en Render
1. Sube estos archivos a la raíz de un repositorio de GitHub.
2. En Render: **New → Static Site** y selecciona el repositorio.
3. Build command: vacío. Publish directory: `.`
4. Deploy.

Para verlo en local basta con abrir `index.html` en el navegador.
